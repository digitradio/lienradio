Comment ajouter un nouveau fichier MP3 ?

  1. Déposez votre fichier audio dans le dossier mp3/ de votre dépôt GitHub.
  2. Si vous utilisez playlist.json, ajoutez le nom du fichier dans la liste (ou le script GitHub Actions peut l'automatiser).
  3. Votre lien direct sera immédiatement accessible et prêt à être écouté !
